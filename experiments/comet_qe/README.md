# comet_qe — a regression head over COMET encoders (§5 of the paper)

This folder holds the trained reference-free QE system of the paper: a hybrid regression head on
top of a COMET-family encoder, adapted from the SurreyCTS hybrid regression framework (BEA 2026).
It predicts a per-pair DA target from `source` + `mt` and is evaluated with Spearman ρ on the
IndicQE-APE test split.

The ablation changes **one variable at a time** from a single reference recipe, so every contrast
is within-build:

| arm | what changes | configs |
|---|---|---|
| `A`, `A0` | the reference recipe, and its minimal-feature variant | `qe-A-cometkiwi-full`, `qe-A0-cometkiwi-min` |
| `E1` encoder | XLM-R (no QE pretraining), InfoXLM, COMET-DA (reference-based), CometKiwi (reference-free), CometKiwi-XL | `qe-E1-*` |
| `E2` features | the attention-derived adequacy features and length ratio | `qe-E2-*` |
| `E3` funnelling | multi-layer pooling over encoder layers vs. last layer only | `qe-E3-*` |
| `E4` loss | MSE, Huber (δ = 0.5, 1) and concordance correlation | `qe-E4-*` |
| `E5` target | per-pair z-score, raw DA, per-pair min–max | `qe-E5-*` |
| `J`, `X` | the reference on the six-pair en→Indic frame (`J`), and an X→en reproduction check against published CometKiwi numbers (`X`) | `qe-J-*`, `qe-X-*` |
| `E6`, `E7`, `A4` | LoRA, MT-first input order, a joint language-pair embedding (extensions; not in the paper's tables) | `qe-E6-lora`, `qe-E7-mtfirst`, `qe-A4-lp-joint` |

Seed replicates carry an `-s43`/`-s44` suffix; `-s42new` re-runs an arm whose first run used an
earlier build. The main ablation runs on the five-pair frame the campaign was built on (8,160 test
rows); `J` re-runs the reference on the six-pair frame. The paper's reading of these runs is in §5,
Table 8 and Appendix K: changing only the encoder from XLM-R to CometKiwi gives the largest gain,
removing multi-layer pooling collapses the head at every seed, and per-pair min–max targets help.

## Layout

```
comet_qe/
├── src/            training framework: hybrid_model, model_registry, data_utils, qe_data, losses,
│                   train, evaluate_test, predict, extract_llm_embeddings
├── scripts/        build_qe_data.py (QE frames from the release), gen_qe_configs.py (writes
│                   configs/qe/), extract_comet_encoder.py, extract_embeddings.py,
│                   make_tiny_encoder.py, run_zeroshot_comet.py (zero-shot COMET baselines)
├── configs/qe/     one YAML per run, generated by scripts/gen_qe_configs.py — do not hand-edit
├── configs/templates/  the original BEA configs, kept for reference
├── models/comet-xlmr/  encoder config + tokenizer only (weights are fetched by extract_comet_encoder.py)
├── deploy/         launch_campaign.sh / run_queue.sh: run the queue on a multi-GPU workstation
├── results/campaign/outputs/<run>/  run_summary.json + dev/test predictions for every run
├── results/campaign/zeroshot/       zero-shot COMET metric scores on the same test split
└── tests/          unit tests for the QE data path, input building, model and training loop
```

## Run

```bash
cd experiments/comet_qe
pip install -r requirements.txt
python scripts/extract_comet_encoder.py --help        # fetch an encoder into models/
python scripts/build_qe_data.py --variant enindic     # build the QE frame from the release
python scripts/gen_qe_configs.py                      # (re)write configs/qe/*.yaml
python src/train.py --config configs/qe/qe-A-cometkiwi-full.yaml
python src/evaluate_test.py --config configs/qe/qe-A-cometkiwi-full.yaml
```

The framework resolves paths relative to this folder (`data/`, `outputs/` and `results/` are
created here). For an offline end-to-end smoke test without downloading an encoder:
`python scripts/make_tiny_encoder.py`, `python scripts/build_qe_data.py --variant enindic
--per-pair 40`, then `python src/train.py --config configs/qe/qe-smoke-tiny.yaml`.

The analysis scripts that read these outputs are `analysis/verify_head_numbers.py`,
`analysis/seed_stability.py`, `analysis/make_cometqe_table.py`, `analysis/axis_head_contrast.py`
and `analysis/campaign_report.py`.
